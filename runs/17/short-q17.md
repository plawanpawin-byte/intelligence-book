# การคำนวณรายได้และค่าใช้จ่ายในร้านกาแฟเล็กๆ: ที่มาของแต่ละการเงิน

ในร้านกาแฟเล็กๆ ต้องมีการคำนวณรายได้และค่าใช้จ่ายอย่างละเอียด เพื่อให้สามารถบริหารธุรกิจได้อย่างยั่งยืน และไม่เกิดปัญหาทางการเงิน

### รายได้ (Revenue)
- **รายได้** = ยอดขายอาหาร + ยอดขายเครื่องดื่ม + ยอดขายของขวัญ

> [!example] รายได้ในร้านกาแฟ
> ยอดขายอาหาร + ยอดขายเครื่องดื่ม + ยอดขายของขวัญ = รายได้ทั้งหมด

### ค่าใช้จ่าย (Expenses)
- **ค่าใช้จ่าย** = ค่าเช่าร้าน + ค่าซื้อสินค้า + ค่าบริการ (เช่น ค่าครองชีพ, ค่าขนส่ง)

> [!tip] คำนวณรายได้ - ค่าใช้จ่าย = กำไร (Profit)

### กำไร (Profit)
- **กำไร** = รายได้ - ค่าใช้จ่าย

> [!warning] ถ้ากำไรน้อย อาจมีปัญหาทางการเงิน
