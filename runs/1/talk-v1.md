# การนอนและการจำ: ความลับในการเรียนรู้และความจำ

**การนอนของเราไม่ได้เป็นก้อนเดียว แต่เป็นรอบๆ sleep cycle รอบนึงประมาณเก้าสิบนาที นอนแปดชั่วโมงก็ประมาณห้ารอบ แต่ละรอบมีหลายระยะ แบ่งใหญ่ๆเป็น non REM นอนแรม เอ่อ นอน REM กับ REM sleep**

คุณรู้ไหมว่าทำไมการนอนจึงสำคัญในการเรียนรู้และความจำ? คุณจะเข้าใจว่าการนอนไม่ใช่การเสียเวลา แต่เป็นส่วนหนึ่งของการเรียน และมีวิธีการเตรียมสมองให้พร้อมสำหรับการเรียนรู้ที่ดีที่สุด

## การนอนและการจำ

### พื้นฐานของการนอน

การนอนของเราไม่ได้เป็นก้อนเดียว มันเป็นรอบๆ sleep cycle รอบนึงประมาณเก้าสิบนาที นอนแปดชั่วโมงก็ประมาณห้ารอบ แต่ละรอบมีหลายระยะ แบ่งใหญ่ๆเป็น non REM นอนแรม เอ่อ นอน REM กับ REM sleep REM ย่อมาจาก rapid eye movement ตากลอกไปมาเร็วๆใต้เปลือกตา เป็นช่วงที่ฝันชัดๆ

- **non REM** แบ่งย่อยเป็นสามระยะ N1 N2 N3
- **REM** ช่วยลดความรุนแรงของอารมณ์ที่ติดมากับความทรงจำ
- **ความจำ** คือการเก็บข้อมูลไว้ในสมอง

### ความจำและการนอน

ตอนกลางวันที่เราเรียนอะไรใหม่ๆ ข้อมูลถูกเก็บชั่วคราวที่ ฮิปโปแคมปัส hippocampus เหมือน inbox ตอนหลับลึก สมองเล่นซ้ำข้อมูลพวกนั้น replay แล้วค่อยๆย้ายไปเก็บถาวรที่เปลือกสมอง neocortex เรียกว่า memory consolidation การรวบรวมความจำ

- **การรวบรวมความจำ** เกิดขึ้นที่ฮิปโปแคมปัส
- คนที่มี **sleep spindle** เยอะหลังเรียน จำได้ดีกว่า

### งานวิจัยและคำแนะนำ

ของ แมทธิว วอล์กเกอร์ คนเขียน Why We Sleep ให้กลุ่มนึงอดนอนทั้งคืน อีกกลุ่มนอนปกติ วันรุ่งขึ้นให้เรียนข้อมูลใหม่ กลุ่มอดนอน ความสามารถสร้างความจำใหม่ลดลงประมาณสี่สิบเปอร์เซ็นต์

- **การนอน** ไม่ใช่การเสียเวลา มันคือส่วนนึงของการเรียน
- **อ่านก่อนนอนแล้วนอนเลย** ดีกว่าอ่านแล้วไปเล่นเกมต่อ

### ทริคในการนอนและเตรียมสมองให้พร้อม

1. ผู้ใหญ่ควรนอนเจ็ดถึงเก้าชั่วโมง วัยรุ่นแปดถึงสิบ
2. นอนตื่นเวลาเดียวกันทุกวัน รวมวันหยุด
3. คาเฟอีน ค่าครึ่งชีวิตประมาณห้าถึงหกชั่วโมง กาแฟบ่ายสาม สามทุ่มยังเหลือครึ่งนึงในเลือด
4. **แอลกอฮอล์** ดื่มแล้วหลับเร็วจริง แต่มันกด **REM** แล้วทำให้ตื่นกลางดึกบ่อย
5. ห้องนอนเย็นๆมืดๆ งานวิจัยฝั่งตะวันตกแนะนำสิบแปดถึงยี่สิบองศา บ้านเราไม่ต้องขนาดนั้น เอาแค่เย็นสบาย
6. **แสงจากจอ** ชั่วโมงก่อนนอนลดมือถือ แสงสว่างตอนกลางคืนกดการหลั่งเมลาโทนิน ฮอร์โมนที่บอกว่าถึงเวลานอน
7. การงีบ งีบสั้นๆประมาณยี่สิบนาที ไม่ลงไปหลับลึก ตื่นมาไม่มึน หรืองีบเก้าสิบนาทีให้ครบรอบไปเลย

### ## ข้อสำคัญที่เราต้องรู้

* ==การนอนเป็นส่วนหนึ่งของการเรียนรู้และความจำ == เราสามารถสร้างความจำใหม่ได้เมื่อเรานอนอย่างเหมาะสม
* ==การรวบรวมความจำเกิดขึ้นที่ฮิปโปแคมปัสหลังจากเราเล่นซ้ำข้อมูล == การเล่นซ้ำข้อมูลจะช่วยให้เรารวบรวมความจำได้
* ==การอดอาหารหรือการกินคาเฟอีนมากเกินไปจะทำให้การนอนลดลง == เราควรควบคุมการกินและดื่มเพื่อให้การนอนเป็นไปอย่างเหมาะสม
* ==การนอนเย็นๆมืดๆสามารถช่วยให้เราหลับลึกและรักษาความจำได้ == เราควรสร้างสภาพแวดล้อมที่เหมาะสมสำหรับการนอน
* ==การงีบตั้งแต่เล็กจะช่วยให้เรามีความจำที่ดีในอนาคต == การงีบอย่างสม่ำเสมอจะช่วยให้เรามีความจำที่ดี
